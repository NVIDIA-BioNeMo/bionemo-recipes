# Open package bugs

Open bugs and capability gaps in Stitch-owned collation, datasets, artifacts,
and worker integration. Framework limitations belong in
[`upstream-gaps.md`](upstream-gaps.md). Closed entries are removed; `B-`
identifiers stay stable and must not be reused.

Imported from Stitch `c3f389af` (2026-10-02). Reproductions and qualification
limits below describe the upstream snapshot, not new BioNeMo GPU validation.

| ID  | Bug and current handling                                                                                                                                                                                                                                                                                                                                             | Fix and verification needed                                                                                                                                                                                                                                                                                 |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| B-3 | **Async vLLM worker lifecycle.** `EncoderVllmGenerationWorker` extends the synchronous worker and lacks `post_init_async` and `generate_async`. On pinned NeMo RL `b03da0f4`, selecting an async engine still replaces its worker with the extension, then calls those missing methods. Non-colocated placement avoids U-67 but does not supply the async interface. | Provide a modality-independent async extension using upstream public construction hooks. Preserve plugin registration and rollout architecture translation, register the async worker interpreter, and qualify multimodal generation/refit plus module-owned projector training, checkpointing, and resume. |
| B-2 | **Joint projector GRPO on combined meshes and multi-rank resume.** TP=1/CP=1 admission supports expert parallelism and replicated HSDP individually. Combined dense replication and EP remains rejected under [U-66](upstream-gaps.md). Upstream reports multi-rank updates for each individual mesh, but no qualified multi-rank GRPO resume.                       | Qualify the combined mesh once the framework supports it, and a real multi-rank checkpoint save/resume. Verify artifact warm start, KL anchor, gradient synchronization, full-feature scatter, optimizer restoration, and projected rollout inputs through public APIs.                                     |
| B-1 | **Multi-pack microbatch collation.** Setting both `step_scheduler.local_batch_size=2` and `dataloader.batch_size=2` fails in `packed_collate_fn`: `feature packs require dataloader batch_size=1, got 2`. Gradient accumulation adds packs per optimizer step but keeps one pack per forward, so it cannot amortize the per-forward all-gather.                      | Let packed datasets and collation accept multiple packs per microbatch, using a batch axis or concatenation with per-pack sequence offsets. Verify token geometry, pack-boundary masking, loss normalization, and a real multi-pack GPU update.                                                             |
